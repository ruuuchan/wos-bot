# WOS 準備フェーズ申請ボット

Discordの中で申請を受け付け、`/集計` で「時間割り」と「兵舎・英雄一覧」の画像2枚をまとめて投稿するボットです。

## 使い方

**メンバー**
- 申請チャンネルの「📝 申請する／回答を直す」ボタンを押す（`/申請` でも可）
- ①同盟・参加時間・希望時間帯 → ②兵舎・英雄 → ③火晶・加速 の順に入力
- 名前の入力は不要です（Discordの表示名が使われます）。もう一度申請すると上書きされ、前回の内容が最初から入っています
- `/自分の回答` で内容を確認できます

**運営（サーバー管理権限のある人だけ使えます）**
| コマンド | 内容 |
|---|---|
| `/イベント設定 開始:2026-11-02 09:00 締め切り:2026-11-01 21:00` | 対象期間の開始と締め切りを設定（タイトルも変更可）。締め切りの時刻に、コマンドを打ったチャンネルへ結果が自動投稿されます |
| `/申請パネル` | 今いるチャンネルに申請ボタンを設置 |
| `/集計` | 時間割りと兵舎・英雄一覧の画像2枚をいつでもまとめて投稿（途中経過の確認にも） |
| `/同盟追加 名前:○○` | 同盟の選択肢を追加（`位置` で何番目に入れるか指定可） |
| `/同盟削除 名前:○○` | 同盟の選択肢を削除（候補から選べます） |
| `/英雄追加 名前:○○` | 英雄の選択肢を追加（置き直し不要、最大25人） |
| `/英雄削除 名前:○○` | 英雄の選択肢を削除（候補から選べます） |
| `/選択肢一覧` | 今の同盟・英雄の選択肢を確認 |
| `/リセット` | 次のイベント用にリセット。「火晶・加速・希望時間だけ」なら同盟・兵舎・英雄は残り、次の申請で最初から入っています |

## 次のイベントの流れ
1. `/リセット` →「火晶・加速・希望時間だけ消す」
2. `/イベント設定` で新しい開始日時と締め切りを入れる
3. `/申請パネル` でボタンを置き直す（締め切りが表示されます）
4. 締め切りの時刻に結果が自動で投稿されます

## 割り振りのルール
火晶が多い順（同じなら加速が多い順）に、本人が希望した時間帯の中で一番早い空き枠（30分）に入れます。希望枠がすべて埋まっていた人は、時間割り画像の下にまとめて表示されます。

## 項目の変更
`config.py` で兵舎レベルの選択肢・参加時間の選択肢・1枠の長さを変えられます。同盟と英雄はDiscordの `/同盟追加` `/同盟削除` `/英雄追加` `/英雄削除` で変えられます（`config.py` の値は最初の初期値です）。今の選択肢は `/選択肢一覧` で確認できます。

## 導入手順

### 1. ボットを作る
1. https://discord.com/developers/applications で「New Application」→ 名前を付けて作成
2. 左メニュー「Bot」→「Reset Token」でトークンを表示してコピー（**他人に見せない**）
3. 左メニュー「OAuth2」→「URL Generator」で
   - SCOPES：`bot` と `applications.commands`
   - BOT PERMISSIONS：`Send Messages`、`Attach Files`、`Embed Links`、`View Channels`
4. 下に出たURLを開き、自分のサーバーに追加

### 2. サーバーに置く（Railwayの例）
1. このフォルダをGitHubのリポジトリにアップロード
2. https://railway.app で「New Project」→「Deploy from GitHub repo」でそのリポジトリを選択（Dockerfileで自動的に動きます）
3. 「Variables」に以下を追加
   - `DISCORD_TOKEN`：1でコピーしたトークン
   - `GUILD_ID`：サーバーID（サーバー名を右クリック →「IDをコピー」。開発者モードをONにすると出ます）。複数のサーバーで使うときはカンマ区切り（例：`111,222`）。ここに入れたサーバーでだけコマンドが使えます
4. 「Volumes」で `/data` にボリュームを追加（再起動しても回答が消えないようにするため）

### 自分のPCで試す場合
```
pip install -r requirements.txt
DISCORD_TOKEN=xxxx GUILD_ID=xxxx python bot.py
```
画像に日本語フォント（Noto Sans CJK）を使います。Macなら環境変数 `FONT_REGULAR` / `FONT_BOLD` に手持ちの日本語フォント（例：`/System/Library/Fonts/ヒラギノ角ゴシック W3.ttc`、`W6.ttc`）を指定してください。

### VPS（Ubuntu）に置く場合
root で次の1行を実行すると、専用ユーザー `wosbot` で動くように設定されます（途中でトークンとサーバーIDを聞かれます）。
```
bash <(curl -fsSL https://raw.githubusercontent.com/ruuuchan/wos-bot/main/deploy/install.sh)
```
更新するときも同じ1行を実行するだけです。トークンを変えたいときは `/etc/wosbot.env` を編集して `systemctl restart wosbot`。

### ほかのサーバーにも入れる
1. Developer Portal の「Bot」で「Public Bot」をON
2. そのサーバーの管理者に招待URLを開いてもらう
3. VPSの `/etc/wosbot.env` の `GUILD_ID=` にそのサーバーIDをカンマ区切りで足して `systemctl restart wosbot`
